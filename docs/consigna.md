Les recuerdo que el 27/09 es la fecha límite para la segunda entrega del Proyecto Final.

Para realizar la entrega no deben enviar archivos por este medio. Simplemente incorporen al repositorio todo el material correspondiente a esta instancia y, una vez actualizado, compartan aquí en el grupo el enlace al repositorio para que pueda realizar la revisión y devolución.

Para la documentación les recomiendo utilizar archivos de texto en formato Markdown, como README.md, en lugar de PDF. Esto facilita mucho la lectura, la navegación por el proyecto, el seguimiento de los cambios y las sucesivas devoluciones.

Si en la primera entrega utilizaron PDF u otro formato, pueden aprovechar esta instancia para reorganizar la documentación. No es necesario complicar la estructura: pueden tener un README.md principal y, si necesitan separar contenidos, otros archivos .md dentro del repositorio.

Cuando incorporen diagramas, modelos, capturas u otras imágenes, guárdenlas también dentro del repositorio y enlácelas desde el mismo archivo Markdown, de manera que la documentación pueda recorrerse directamente desde GitHub sin tener que descargar archivos adicionales.

La idea es que el repositorio vaya convirtiéndose progresivamente en la documentación completa y ordenada del proyecto, además de contener el código fuente.

El cumplimiento de la fecha de entrega se verificará mediante la fecha de los commits realizados en el repositorio, por lo que no es necesario realizar ningún envío adicional.
